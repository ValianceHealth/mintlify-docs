An API key can call only the models on this page. Every other model id returns
`400` with `code: "model_not_allowed"`. The list is the same for every
customer.

A model is on this page because we assessed where it runs. Each one has a
named destination and its own PDPA transfer impact assessment (TIA). We share
the TIA under NDA. If residency is a requirement for you, ask before you build.

Whatever model you pick, the redaction path is the same: identifiers do not
reach the model.

`model` is required on every request. There is no default model.

## What "provider retention" means

- **None**: the provider keeps no copy of your request or of the answer.
- **Abuse-detection exception**: AWS's abuse classifier runs on GPT-5.6
  traffic. If it flags a request, AWS keeps that request for up to 30 days for
  automated review, in the region that processed it. AWS does not share it
  with OpenAI. If your policy forbids any provider-side retention, use a Nova,
  Claude or DeepSeek model.
- On Azure, automated real-time review can still run. It stores nothing.

## Calling a model

```bash
curl https://api.v2.healthproximate.com/api/v1/llm/chat/completions \
  -H "Authorization: Bearer hpx_..." \
  -H "Content-Type: application/json" \
  -d '{
    "model": "apac.amazon.nova-pro-v1:0",
    "messages": [{"role": "user", "content": "Summarize this discharge note: ..."}]
  }'
```

`GET /api/v1/llm/models` returns the models your key can call, in the OpenAI
list shape.

<Info>
  There is no region or routing parameter on the request. The model id
  decides where the request runs, so the model id is the whole choice.
</Info>

Tool calls work as described in [tool calling](/api/tool-calling).

## Errors you may see

| Status | Code | Meaning |
| --- | --- | --- |
| `400` | `model_not_allowed` | The model is not on this page. Pick one that is. |
| `403` | `{"error": "model_not_allowed"}` | Your organization is on the free plan, which cannot call these models. This body is not OpenAI-shaped. Contact us to upgrade. |
| `503` | — | The redaction engine is unavailable. The gateway fails closed. It does not send text that is not redacted. |

See [Errors & limits](/api/errors-and-limits) for the full error contract.
