The gateway serves models from five providers. Every destination is **named and assessed**: our PDPA Transfer Impact Assessment is complete, and inference runs under our signed BAAs (AWS and Microsoft Azure). Whatever model you pick, the redaction path is identical — identifiers never reach the model.

If you omit `model`, the gateway uses `apac.amazon.nova-pro-v1:0`.

## Amazon

| Model ID | Tier | Residency |
| --- | --- | --- |
| `apac.amazon.nova-pro-v1:0` | Standard (default) | APAC-bounded, 10 `ap-*` regions |
| `apac.amazon.nova-lite-v1:0` | Light | APAC-bounded, 10 `ap-*` regions |
| `apac.amazon.nova-micro-v1:0` | Micro | APAC-bounded, 10 `ap-*` regions |

Bedrock `apac` inference profiles. Verified routing set: `ap-southeast-1..5`, `ap-northeast-1..3`, `ap-south-1..2`. No US, no EU.

## Choosing a model

```bash
curl https://api.v2.healthproximate.com/api/v1/llm/chat/completions \
  -H "Authorization: Bearer hpx_..." \
  -H "Content-Type: application/json" \
  -d '{
    "model": "global.anthropic.claude-sonnet-5",
    "messages": [{"role": "user", "content": "Summarize this discharge note: ..."}]
  }'
```

<Info>
  **Per-organization clearance.** Your contract can restrict the menu — for example, APAC-resident models only. In that case, models outside your clearance return `403` with `code: "model_not_allowed"`.
</Info>

## Errors you may see

| Status | Code | Meaning |
| --- | --- | --- |
| `403` | `model_not_allowed` | The model is outside your organization's clearance. Pick a model from your cleared set. |
| `503` | — | The redaction engine is unavailable. The gateway fails closed rather than forward un-redacted text. |

See [Errors & limits](/api/errors-and-limits) for the full error contract.
