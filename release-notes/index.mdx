This page tracks customer-facing updates to Healthproximate — product improvements,
API changes, and documentation updates. It's intentionally light at launch and will
grow with a regular cadence.

<Update label="2026-07" description="AI workspaces — documents & promote-to-chat">
  ### Workspace documents and promote-to-chat

  - Added [Workspaces](/ai/workspaces) documentation covering how a workspace holds both
    uploaded **files** and authored **documents**, and how to control what the chat
    assistant uses.
  - Documented the five document types (Note, Runbook, Memory note, Skill template,
    Workspace instructions) and the **promote-to-chat** lifecycle — including the
    one-active-Workspace-instructions rule and the automatic removal from chat when a
    promoted document is edited, re-typed, or archived.

  *Feature currently available to superusers.*
</Update>

<Update label="2026-06" description="Public documentation — Stage 1">
  ### Public documentation launches

  - Published the first public Healthproximate help center: product overview, getting
    started and onboarding, the five core workflow guides
    ([Entity Resolver](/workflows/entity-resolver),
    [Dashboard](/workflows/dashboard),
    [Analytics](/workflows/analytics),
    [Predictions](/workflows/predictions),
    [Simulation](/workflows/simulation)),
    an [API Overview](/api/overview), [FAQ](/faq), and [Support](/support) pages.
  - Established the public-vs-restricted documentation boundary: curated public
    guidance here, with detailed implementation references available through
    controlled access channels.
</Update>

<Update label="2025-10" description="Secure File Upload API v1.0">
  ### Secure File Upload API — initial release

  - Presigned-URL uploads for secure, direct-to-storage file transfer.
  - Organization-based file isolation.
  - Automatic filename sanitization.
  - Multipart upload support for large files.
  - API-key authentication and comprehensive error handling.

  *Sourced from the Healthproximate Secure File Upload API changelog.*
</Update>
